# Treat static sites served from a subdirectory as static

## Request
Static sites served from a subdirectory are typed "empty". app/Services/WizardData.php:181 requires app_type === 'static', but site typing only emits that when index.html sits in the root. A /_site Jekyll site keeps demanding PHP, DB, env template, and the cutover env check never passes.
