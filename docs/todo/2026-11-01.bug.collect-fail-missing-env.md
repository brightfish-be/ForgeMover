# Fail collect on missing .env for non-static sites

## Request
Collect no longer fails on a missing .env. app/Services/RelocationSteps.php:44 prints a "static site?" warning and exits 0 for any site type. A Laravel site with a lost .env is collected without its database, and restore also exits 0. Suggested fix: pass the PHP-side static flag into the script and keep the hard failure for non-static sites.
